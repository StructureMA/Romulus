Getting Started

  • Type dash in any terminal to open this dashboard
  • The server runs automatically on login via macOS LaunchAgent (port 3333)
  • Data auto-saves — no need to manually save anything

Managing Projects

  • Click any row to expand the edit panel — change status, type, notes, and account assignments
  • Search by project name, package name, or notes
  • Filter by status (Active/Paused/Archived) or type (Mobile/Web App/etc.)
  • Sort by clicking any column header (click again to reverse)
  • Re-scan when you add/remove project directories — picks up new projects automatically

Accounts

  • Each project can have a default account and per-service overrides
  • Example: Portfolio uses jonmlucia@gmail.com for Vercel but structma@yahoo.com for Cloudflare
  • To add a new account, edit ~/project-dashboard/user-data.json and add to the accounts array

Files

  • ~/project-dashboard/projects-data.json — auto-generated by scanner (overwritten on re-scan)
  • ~/project-dashboard/user-data.json — your edits (never touched by scanner)
  • ~/project-dashboard/scanner.mjs — the filesystem crawler
  • ~/project-dashboard/server.mjs — Express server on port 3333

CLI Commands

  • dash — open dashboard in browser
  • cd ~/project-dashboard && node scanner.mjs — re-scan from CLI
  • launchctl stop com.jonathanlucia.command-center — stop the server
  • launchctl start com.jonathanlucia.command-center — start the server

Step-by-step guides for cleaning up each service when decommissioning a project. Expand the relevant service(s) below.

GitHub — Archive or Delete Repo
  1. Go to the repo on github.com → Settings (bottom of sidebar)
  2. To archive (recommended): Scroll to "Danger Zone" → "Archive this repository" → Confirm
  3. To delete: Scroll to "Danger Zone" → "Delete this repository" → Type the repo name to confirm
  4. Locally: rm -rf ~/project-name (or just leave it, it won't hurt anything)
Vercel — Remove Project
  1. Log in at vercel.com with the correct account (check the Account column!)
  2. Go to the project → Settings → scroll to bottom
  3. Click "Delete Project" → type project name to confirm
  4. If the project has a custom domain, remove the domain first under Settings → Domains
  5. Locally: rm -rf ~/project-name/.vercel
  6. CLI alternative: npx vercel remove project-name

⚠️ Remember: you have projects on BOTH jonmlucia@gmail.com and structma@yahoo.com Vercel accounts

Expo / EAS — Remove Project
  1. Go to expo.dev → Your Projects
  2. Find the project → click the ⋯ menu → Delete
  3. This removes EAS Build history, update channels, and credentials
  4. Locally: remove app.json expo config or the whole directory
  5. CLI: eas project:delete (from the project directory)

⚠️ If the app is on the App Store/TestFlight, removing from Expo doesn't remove it from Apple — do that separately in App Store Connect

Firebase — Delete or Disable Project
  1. Go to console.firebase.google.com
  2. Select the project → Project Settings (gear icon)
  3. Scroll to bottom → "Shut down project"
  4. This gives you 30 days to recover before permanent deletion
  5. To just disable billing: Go to GCP Console → Billing → unlink the project
  6. Locally: rm .firebaserc firebase.json
Supabase — Pause or Delete Project
  1. Go to supabase.com/dashboard
  2. Select the project → Settings → General
  3. To pause (free, reversible): Click "Pause project" — data is preserved but APIs stop
  4. To delete (permanent): Click "Delete project" → type name to confirm
  5. Locally: remove supabase/ directory and Supabase env vars from .env

💡 Pausing is free and keeps your data — good option if you might return to the project

Cloudflare — Delete Worker or Pages Project
  1. Log in at dash.cloudflare.com
  2. Workers: Workers & Pages → select worker → Settings → Delete
  3. Pages: Workers & Pages → select project → Settings → Delete
  4. D1 databases: Workers & Pages → D1 → select database → Delete (do this BEFORE deleting the worker)
  5. Custom domains: If the worker/page has a custom route, remove it from DNS first
  6. Locally: rm wrangler.toml or the whole directory
  7. CLI: npx wrangler delete (from the project directory)
Netlify — Delete Site
  1. Go to app.netlify.com
  2. Select the site → Site configuration → scroll to bottom
  3. Click "Delete this site" → type site name to confirm
  4. If using a custom domain, remove it from Netlify first, then update DNS
  5. Locally: rm -rf .netlify netlify.toml
Full Project Cleanup Checklist
  1. Check the Account column — make sure you're logging into the right account for each service
  2. Remove custom domains and DNS records first (Cloudflare DNS panel)
  3. Delete from hosting services (Vercel, Netlify, Cloudflare Pages)
  4. Delete databases (Supabase, D1, Firestore) — export data first if needed
  5. Remove from Expo/EAS if it's a mobile app
  6. Archive the GitHub repo (don't delete — you might want the code later)
  7. Delete the local directory if you don't need the code
  8. Come back here and re-scan — the project will disappear from the dashboard
  9. Update status to "Archived" first if you want to keep a record of it

Update Portfolio via Claude Code

Click the "✎ Update Portfolio" button in the top bar to open a new Terminal window with Claude Code, pre-loaded with a prompt that includes your current active and archived projects.

Claude will:

  • Open your portfolio project at ~/portfolio
  • Review what's currently shown on jonathanlucia.com
  • Compare against your active/archived projects from this dashboard
  • Suggest or make updates to feature new projects and remove old ones

How It Works

  • The button generates a prompt from your current project data (active vs archived)
  • It opens a new Terminal window and runs claude in your portfolio directory
  • The prompt is saved to ~/project-dashboard/.portfolio-prompt.txt for reference

Tip: You can also copy the generated prompt and paste it into any Claude session manually.
